I’m Konstantinos, a software engineer and Android developer based in Athens, Greece. I currently work as an Android Engineer at Alpha Bank, with previous experience at Almende B.V., StandBy Solutions B.V. and Softship GmbH.

My focus is native Android with Kotlin, modern UI with Jetpack Compose, and maintainable software through MVVM and Clean Architecture. I also work with Kotlin Multiplatform and enjoy exploring how shared code can support great mobile experiences.
